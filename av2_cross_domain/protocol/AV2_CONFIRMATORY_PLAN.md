# AV2 Confirmatory Plan

FROZEN PRE-VAL PLAN

The pre-VAL confirmatory plan fixed 5,000 bootstrap replicates (seed 2026090721) with two-sided 95% confidence intervals and 5,000 pseudo-nearest replicates (seed 2026090722). Gate 1 passed only if the lower bound of the 95% confidence interval for the aggregate H→C endpoint-loss gain exceeded zero. Gate 2 passed only if the 95% confidence interval for λ excluded zero and the two-sided add-one pseudo-nearest P value was <0.05. For the pseudo-nearest test, null extremeness was defined by |λ_null| ≥ |λ_obs|. Positive λ was not an additional formal Gate 2 requirement. The plan was locked before official VAL access.
